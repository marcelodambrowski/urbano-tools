1
Execução do Instalador e Support Path
Instalação de arquivos e configuração do CAD

O arquivo Setup_UrbanoTools_v1.0.exe copia toda a estrutura de arquivos e registra automaticamente a pasta do sistema na lista de busca (Support Path) do seu AutoCAD ou Civil 3D.

1.1 Execução do Setup
  • 1Execute o arquivo Setup_UrbanoTools_v1.0.exe.
  • 2Selecione o idioma do assistente e avance.
  • 3Mantenha o diretório fixado em C:\urbano-tools e prossiga até a conclusão.
Local fixo de instalação: C:\urbano-tools
1.2 Configuração do Support Path no CAD

Configuração Automática (Recomendada): Durante o processo, o instalador já insere o caminho C:\urbano-tools diretamente no Registro do CAD. Na maioria das vezes, você não precisará fazer nada.

Configuração Manual (Fallback): Caso utilize uma versão específica do AutoCAD, tenha instalado o software após o Urbano Tools ou precise checar o caminho manualmente, siga o procedimento:

  • 1Abra o AutoCAD/Civil 3D, digite o comando OPTIONS na linha de comando e pressione Enter.
  • 2Navegue até a aba Files e expanda a opção Support File Search Path.
  • 3Clique em Add..., depois em Browse... e selecione a pasta C:\urbano-tools.
  • 4Clique em Apply e em OK.
OPTIONS → Files → Support File Search Path → Add: C:\urbano-tools
2
Instalação do Python e das Bibliotecas
Ambiente necessário para rotinas avançadas e mapas

Diversas ferramentas do Urbano Tools dependem do interpretador Python e de suas bibliotecas para geoprocessamento e manipulação de dados espaciais.

2.1 Download e Instalação do Python

Clique no botão abaixo para baixar o instalador oficial do Python:

Baixar Instalador do Python (64-bit .exe)
Atenção Obrigatória: Ao abrir o instalador do Python, lembre-se de marcar a caixa "Add python.exe to PATH" na parte inferior da primeira janela antes de clicar em "Install Now".
2.2 Instalação das Bibliotecas Python

Após terminar a instalação do Python, acesse a pasta do sistema e execute o arquivo de automação para baixar os pacotes necessários:

  • 1Abra a pasta C:\urbano-tools no seu Explorador de Arquivos.
  • 2Dê um duplo clique no arquivo _1.install_bibliotecas_python.bat.
  • 3Aguarde a janela preta (Prompt de Comando) finalizar a instalação automática das dependências e fechar.
Executar: C:\urbano-tools\_1.install_bibliotecas_python.bat
3
Ativação da Licença
Sistema Porteira — via botão "Status da Licença" na Ribbon

O Urbano Tools utiliza o sistema de licenciamento integrado Porteira.

Passos para ativação
  • 1Na Ribbon (barra superior) do AutoCAD, clique na aba do Urbano Tools e escolha o botão Status da Licença.
  • 2Na janela exibida, identifique o seu ID do cliente e a situação atual da sua licença.
  • 3Clique no botão Ativar / Renovar Licença para enviar uma mensagem com seu ID ao suporte via WhatsApp.
  • 4Após a liberação pelo suporte, clique no botão Atualizar Status dentro da mesma janela para validar online.
Uso Offline: A validação salva o registro localmente, permitindo que as ferramentas continuem funcionando mesmo se você ficar sem internet temporariamente.

Dúvidas frequentes
Perguntas comuns na instalação
O que faz o arquivo _1.install_bibliotecas_python.bat?
Ele baixa e instala automaticamente no Python todas as bibliotecas e pacotes necessários para o funcionamento das rotinas de geoprocessamento e ferramentas do Urbano Tools.
Esqueci de marcar a opção "Add python.exe to PATH", o que faço?
Execute o instalador do Python novamente, clique em Modify (ou Reinstalar) e certifique-se de marcar a opção "Add python.exe to PATH". Em seguida, execute o _1.install_bibliotecas_python.bat novamente.
O instalador grava o Support Path no AutoCAD sozinho?
Sim! O executável insere o diretório C:\urbano-tools no Registro do sistema operacional para o seu CAD automaticamente. A inclusão manual através do comando OPTIONS serve apenas como um plano de reserva (fallback).
Onde os arquivos do sistema ficam salvos?
Toda a estrutura do pacote fica centralizada no diretório fixo C:\urbano-tools. Recomendamos não renomear ou mover essa pasta.
