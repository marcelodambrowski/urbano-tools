urbanotoolsManual de Instalação e Ativação
Instale e ative o Urbano Tools no seu AutoCAD ou Civil 3D em 5 etapas.
Este guia cobre a instalação do Python, o instalador do Urbano Tools (com a configuração automática do Civil 3D), as bibliotecas Python, a primeira abertura no CAD e a ativação da sua licença.
Preciso de ajuda Ver as etapas ↓ Baixar em PDF
Antes de começar
O que você precisa
Windows 10 ou 11 (64 bits)

Não precisa ser administrador: o instalador grava tudo no seu próprio usuário.

AutoCAD ou Civil 3D

Civil 3D 2023 a 2027 é configurado automaticamente. Nas demais versões, o caminho é incluído à mão (etapa 4).

Internet

Para baixar o Python e as bibliotecas e para ativar a licença. Depois, funciona até 30 dias sem conexão.

1
Instalação do Python
Interpretador usado pelas janelas e cálculos do Urbano Tools

Várias ferramentas (licença, divisão de área, níveis, arbóreas, ondulação geoidal, tabelas com latitude/longitude, SIGEF e otimização de TIF) usam o Python. Se você já tem o Python 3 instalado pelo python.org, pode pular para a etapa 2.

Baixar Python 3.14.8 (Windows 64 bits) Outras versões no python.org
  • 1Abra o instalador baixado.
  • 2Na primeira tela, marque "Add python.exe to PATH" (parte de baixo da janela).
  • 3Clique em Install Now e aguarde até aparecer "Setup was successful".
Use o Python do python.org, não o da Microsoft Store. O Urbano Tools ignora o atalho da Store (pasta WindowsApps). Se for usar "Customize installation", deixe marcada a opção tcl/tk and IDLE: as janelas do Urbano Tools dependem dela.
2
Execução do instalador do Urbano Tools
Copia os arquivos e configura o Support Path do Civil 3D

O arquivo Setup_urbano-tools-10.4.exe (o número muda conforme a versão) copia o programa, registra a pasta escolhida e, se você deixar marcado, inclui essa pasta no Support Path de todos os perfis do Civil 3D encontrados no computador.

Feche o AutoCAD / Civil 3D antes de começar. Se ele estiver aberto, o instalador avisa: as alterações no Support Path podem não ser salvas com o programa em execução.
2.1 Passo a passo do assistente
  • 1Execute o Setup_urbano-tools-10.4.exe e escolha o idioma (Português do Brasil ou English).
  • 2Pasta de instalação: o padrão é C:\urbano-tools e é o recomendado. Você pode escolher outra pasta, exceto Arquivos de Programas ou a pasta do Windows, e o caminho não pode ter ponto e vírgula (;). Numa atualização, o instalador reaproveita a pasta usada antes.
  • 3Componentes: "Urbano Tools" é obrigatório. Deixe marcada a opção "Configurar Support Path no AutoCAD Civil 3D (2023-2027)".
  • 4Clique em Instalar. Ao terminar, aparece um resumo com cada versão e perfil do Civil 3D configurado (ex.: Civil 3D 2025 [<<C3D_Metric>>]: OK).
  • 5Na última tela, deixe marcada a caixa "Instalar as bibliotecas Python agora" e clique em Aplicar e Concluir. A janela de bibliotecas da etapa 3 abre em seguida.
Pasta recomendada: C:\urbano-tools
Não apareceu a caixa das bibliotecas? Ela só aparece quando o Python já está instalado. Sem problema: faça a etapa 1 e depois siga a etapa 3 pelo duplo clique no arquivo.
Segurança da pasta: quando instalado fora da sua pasta de usuário (como em C:\urbano-tools), o instalador restringe a pasta ao seu usuário, ao sistema e aos administradores, para que outras contas do computador não alterem os arquivos.
3
Instalação das bibliotecas Python
pyproj, pdfplumber e rasterio, no mesmo Python usado pelo AutoCAD

A janela "Bibliotecas Python" mostra qual Python o AutoCAD vai usar, verifica cada biblioteca e instala o que estiver faltando. Ela abre de três jeitos:

  • AAutomaticamente no final do instalador (caixa da etapa 2.5).
  • BCom duplo clique no arquivo 1_instalar_bibliotecas.pyw, na pasta de instalação. Não precisa abrir o AutoCAD.
  • CNo AutoCAD, pelo comando URBANO_PYTHON → opção Instalar bibliotecas. Se algum comando precisar de uma biblioteca ausente, ele também oferece instalar na hora.
C:\urbano-tools\1_instalar_bibliotecas.pyw
Na janela
  • 1Confira em "Python usado pelo AutoCAD" o caminho do python.exe. Para usar outro, clique em Trocar...
  • 2Clique em Instalar / atualizar e aguarde (pode levar alguns minutos; o andamento aparece no quadro de mensagens).
  • 3Pronto quando todas as linhas mostrarem "instalada" e o rodapé disser "Tudo instalado." O botão Verificar refaz a conferência sem instalar nada.
BibliotecaUsada em
tkinterTodas as janelas (já vem com o Python)
pyprojTabela de coordenadas (Lat/Long) e Área local SGL (SIGEF)
pdfplumberTabela SIGEF a partir do PDF do memorial
rasterioOtimizar TIF / GeoTIFF
Mesmo Python para tudo: o caminho escolhido fica gravado no Windows e é o mesmo que o AutoCAD usa. Assim, as bibliotecas sempre vão para o interpretador que roda as ferramentas.
4
Primeira abertura no AutoCAD / Civil 3D
Carregamento automático, aba na Ribbon e Support Path manual

Ao abrir um desenho, o AutoCAD lê o acaddoc.lsp da pasta do Urbano Tools, que carrega a Ribbon e as ferramentas. A aba Urbano Tools aparece com os painéis Ferramentas, Sistema de Locação de Pontos, Georreferenciamento e Licença.

4.1 Aviso de segurança do AutoCAD

Na primeira abertura o AutoCAD pode exibir "Security - Unsigned Executable File" para o acaddoc.lsp ou o urbano-tools.vlx. Clique em Always Load (Sempre carregar). Para não ver mais o aviso, inclua a pasta em Trusted Locations:

OPTIONS → Files → Trusted Locations → Add: C:\urbano-tools
4.2 Support Path manual (quando a aba não aparece)

O instalador configura sozinho o Civil 3D 2023 a 2027. Faça o procedimento abaixo se você usa o AutoCAD "puro", outra versão, um perfil criado depois da instalação, ou se a aba não apareceu:

  • 1Digite OPTIONS na linha de comando e pressione Enter.
  • 2Na aba Files, expanda Support File Search Path.
  • 3Clique em Add..., depois em Browse... e selecione a pasta de instalação (ex.: C:\urbano-tools).
  • 4Clique em Apply e OK, feche e abra o AutoCAD de novo.
OPTIONS → Files → Support File Search Path → Add: C:\urbano-tools
Inclua a pasta principal (C:\urbano-tools), não a subpasta data. É na principal que fica o acaddoc.lsp.
5
Ativação da licença
Cada computador tem um ID próprio, liberado pelo suporte

Enquanto a licença não estiver ativa, a aba aparece normalmente, mas os comandos mostram "Licença inválida ou expirada" na linha de comando e não executam. Para ativar:

  • 1Na aba Urbano Tools, painel Licença, clique no botão Licença (ou digite URBANO_LICENCA).
  • 2A janela mostra Licenciado para, ID do cliente (formato A3F9-21C7-88D0-4E12), Status (NÃO ATIVADA, ATIVA ou EXPIRADA), Válida até, Dias restantes e Versão instalada.
  • 3Clique em Ativar / Renovar. O WhatsApp abre com uma mensagem pronta contendo o seu ID: é só enviar.
  • 4Depois da confirmação do suporte, clique em Atualizar status. A licença passa para ATIVA e as ferramentas carregam na hora, sem reiniciar o AutoCAD.
Uso sem internet: a última verificação fica salva no computador. As ferramentas continuam funcionando por até 30 dias sem conexão; depois disso, conecte-se para renovar a verificação.
Trocou de computador ou formatou? O ID muda. Abra a janela de Licença no computador novo e envie o novo ID ao suporte.

Atualizações automáticas
Nenhuma ação necessária

Uma vez por abertura do AutoCAD, com a licença ativa e internet disponível, o Urbano Tools verifica se há versão nova. Se houver, ela é baixada em segundo plano, conferida e passa a valer na próxima abertura do AutoCAD. Para verificar na hora, use URBANO_CONEXAO.

Reinstalar o instalador não é necessário para receber novas versões. Use o instalador novamente só se for mudar a pasta de instalação ou se o suporte pedir.

Dúvidas frequentes
Problemas comuns na instalação
A aba "Urbano Tools" não apareceu na Ribbon.
Quase sempre é o Support Path: siga a etapa 4.2 e reinicie o AutoCAD. Se o AutoCAD mostrou um aviso de segurança e você clicou em "Do Not Load", feche, abra de novo e escolha "Always Load".
Aparece "Python não encontrado".
Instale o Python pelo python.org (etapa 1). Se já estiver instalado, rode URBANO_PYTHON → Detectar novamente, ou Escolher python.exe e aponte o arquivo (normalmente em %LOCALAPPDATA%\Programs\Python\Python3xx\python.exe).
Esqueci de marcar "Add python.exe to PATH". E agora?
Não é obrigatório para o Urbano Tools, que também procura o Python nas pastas padrão. Se ele não for encontrado, rode o instalador do Python de novo, clique em Modify e marque a opção, ou indique o caminho com URBANO_PYTHON → Escolher python.exe.
A janela de bibliotecas mostra "FALTA" ou erro do pip.
Verifique a internet e clique em Instalar / atualizar de novo. Em redes corporativas, proxy ou antivírus podem bloquear o download. Se só faltar o tkinter, reinstale o Python mantendo marcada a opção tcl/tk and IDLE.
Ativei a licença, mas os comandos continuam bloqueados.
Na janela de Licença, clique em Atualizar status. Se ainda não mudar, rode URBANO_CONEXAO e envie o resultado ao suporte; ele mostra se o computador consegue falar com o servidor (internet, firewall, proxy).
Posso instalar em outra pasta ou mudar de pasta depois?
Sim. Rode o instalador e escolha a nova pasta: ele tira a pasta antiga do Support Path do Civil 3D e grava a nova. Evite Arquivos de Programas, pois o Urbano Tools precisa gravar na própria pasta para se atualizar.
Como desinstalar?
Em Configurações do Windows → Aplicativos, desinstale Urbano Tools. O desinstalador pergunta se deve remover o caminho do Support Path do Civil 3D. Se você incluiu o caminho à mão (etapa 4.2), remova-o também pelo OPTIONS.
